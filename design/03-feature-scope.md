# # 3. Feature Scope and Priority

[< Back to Overview](00-overview.md)

---

| Capability | Scope | Priority |
| :--- | :--- | :--- |
| Device Discovery | mDNS/Bonjour + HTTP scan + manual IP entry | MVP Required |
| Pairing & Trust | Self-signed TLS certificates, SHA-256 fingerprints, PIN confirmation, trust list, trust revocation | MVP Required |
| Direct Transfer (Receive) | Receive files sent from desktop, acceptance confirmation, progress display | MVP Required |
| Direct Transfer (Send) | Select files from gallery/file manager to send to paired devices | MVP Required |
| Shared Folder (Participate) | Accept share invitations, join shares, participate as a member in sync | MVP Required |
| Background Sync | File watching, periodic scanning, incremental sync, conflict copy retention | MVP Required |
| Shared Folder (Create) | Mobile creates shares, invites devices | Phase 2 |
| Battery Optimization | Intelligent sync frequency, Wi-Fi restriction, background task management | MVP Required |
