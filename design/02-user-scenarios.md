# # 2. User Scenarios

[< Back to Overview](00-overview.md)

---

| Scenario | Description |
| :--- | :--- |
| Scenario 1 | In an office, quickly transfer photos/documents taken on a phone to a desktop PC without cables or cloud services. |
| Scenario 2 | Sync project files from a desktop shared folder to a phone for offline access during business travel. |
| Scenario 3 | Phone discovers nearby devices, establishes trust via PIN pairing, and auto-connects on subsequent encounters. |
| Scenario 4 | Phone receives files sent from a desktop, confirms acceptance, and saves them to a designated directory. |
| Scenario 5 | Direct file transfer between multiple mobile devices (Android <-> iOS). |
